PASSO 1: Criar Projeto Supabase
────────────────────────────────
1. Acesse: https://supabase.com
2. Crie conta ou faça login
3. Clique em "New Project"
4. Preencha nome e senha
5. Aguarde criação (1-2 min)


PASSO 2: Copiar Credenciais
────────────────────────────
1. No painel do projeto, clique em Settings ⚙️
2. Clique em API
3. Copie:
   
   Project URL:
   https://xyzabc123def.supabase.co
   
   ↓ Extraia o ID:
   xyzabc123def
   
   anon/public key:
   eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
   (Bem longo, começa com eyJ)


PASSO 3: Configurar Sistema
────────────────────────────
1. Abra: /utils/supabase/info.tsx
2. Cole suas credenciais:

   export const projectId = 'xyzabc123def';
   export const publicAnonKey = 'eyJ...';

3. Salve o arquivo (Ctrl+S)


PASSO 4: Deploy do Servidor
────────────────────────────
Abra o terminal e execute:

   npm install -g supabase
   supabase login
   supabase link --project-ref xyzabc123def
   supabase functions deploy make-server-8b82752b


PASSO 5: Testar
────────────────────────────
1. Abra Console do navegador (F12)
2. Cole e execute:

   fetch('https://xyzabc123def.supabase.co/functions/v1/make-server-8b82752b/health')
     .then(r => r.json())
 .then(console.log);

3. Deve retornar: {status: "ok"}


✅ PRONTO! Faça login com:
──────────────────────────
Email: admin@sistema.com
Senha: 123456

PROBLEMA: Erro 401 (Não autorizado)
───────────────────────────────────
CAUSA: Credenciais incorretas

SOLUÇÃO:
1. Verifique /utils/supabase/info.tsx
2. Confirme Project ID e Anon Key
3. Salve o arquivo
4. Recarregue página (F5)

Consulte: TROUBLESHOOTING-401.md


PROBLEMA: Erro 404 (Não encontrado)
───────────────────────────────────
CAUSA: Servidor não deployado

SOLUÇÃO:
supabase functions deploy make-server-8b82752b

Verifique: supabase functions list


PROBLEMA: "User profile not found"
──────────────────────────────────
CAUSA: Usuários demo não criados

SOLUÇÃO (No console do navegador):
fetch('https://SEU_PROJECT_ID.supabase.co/functions/v1/make-server-8b82752b/initialize', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer SUA_ANON_KEY',
    'Content-Type': 'application/json'
  }
})


PROBLEMA: Erro de CORS
──────────────────────
CAUSA: CORS não configurado

SOLUÇÃO:
1. Verifique se index.tsx tem: app.use("*", cors())
2. Redeploy: supabase functions deploy make-server-8b82752b


DIAGNÓSTICO AUTOMÁTICO:
───────────────────────
1. Abra: DIAGNOSTIC-SCRIPT.js
2. Substitua credenciais no topo do arquivo
3. Cole todo o código no Console (F12)
4. Pressione Enter
5. Aguarde resultados

Consulte: CHECK-SYSTEM.md
