# Documentos e Anexos

## Anexar ficheiros

Em qualquer registo que suporte anexos (facturas, actas, comunicações, pedidos de compra),
encontrará uma zona de upload. Tipos de ficheiro aceites: PDF, imagens (PNG/JPEG/WEBP/GIF),
documentos Word e Excel, CSV. Outros tipos de ficheiro (ex.: executáveis, HTML) são recusados
por motivos de segurança. Tamanho máximo: 10MB por ficheiro.

## Consultar anexos

Anexos de um registo aparecem listados no próprio registo, com opção de descarregar. Só pode
eliminar um anexo que você próprio carregou, ou se tiver perfil de Administrador do Sistema.

## Exportar documentos (PDF)

Alguns módulos (ex.: Actas) permitem exportar diretamente para PDF a partir do próprio ecrã de
detalhe — procure o botão "Descarregar PDF" ou equivalente.
