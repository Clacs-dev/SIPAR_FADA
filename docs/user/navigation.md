# Painel Principal e Navegação

## O menu lateral

Mostra só os módulos a que o seu perfil (departamento + eventuais permissões adicionais) tem
acesso. Se muda de função ou departamento, o menu muda automaticamente depois do próximo login.

Módulos de negócio típicos, consoante o seu perfil:

- **Dashboard** — visão geral.
- **Agenda** — os seus compromissos (reuniões internas e audiências/apresentações agendadas para si).
- **Cartas de Apresentação** / **Audiências** — pedidos de visita, internos e de entidades externas.
- **Actas** — atas de reuniões.
- **Comunicações** — correspondência interna/externa.
- **Facturas** — ciclo de facturação.
- **Compras** — pedidos de compra, cotações, ordens de compra.
- **Reuniões Internas** / **Salas de Reunião**.
- **Mensagens**, **Notificações**, **Documentos** — utilitários transversais.

Módulos de administração (**Utilizadores**, **Departamentos**, **Roles**, **Auditoria**,
**Diagnóstico do Sistema**, **Licença**, **Configurações**) só aparecem para quem tem o perfil
de Administrador do Sistema — ver [`admin-system.md`](admin-system.md).

## Uma limitação a conhecer

Ao contrário de um site normal, não pode usar os botões "avançar"/"recuar" do browser dentro da
app, nem marcar um ecrã específico nos favoritos por URL — a navegação volta sempre ao painel
principal se a app for recarregada. Isto é uma limitação conhecida, não um erro do seu lado.
