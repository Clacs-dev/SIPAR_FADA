# Manual do Utilizador — SIPAR-FADA

Guia para quem usa a aplicação no dia-a-dia — sem necessidade de conhecimentos técnicos.

## Índice

1. [`getting-started.md`](getting-started.md) — primeiros passos
2. [`login.md`](login.md) — iniciar sessão, recuperar password
3. [`navigation.md`](navigation.md) — o ecrã principal e o menu (inclui o que era "dashboard.md" — no SIPAR-FADA o painel principal *é* o ponto de partida da navegação, não faz sentido separá-los em dois documentos)
4. [`users.md`](users.md) — o seu perfil, dados bancários, assinatura
5. [`notifications.md`](notifications.md) — notificações e mensagens internas (mesma área da app, documentadas juntas)
6. [`documents.md`](documents.md) — anexar e consultar documentos
7. [`reports.md`](reports.md) — relatórios disponíveis
8. [`modules/`](modules/) — um guia por módulo de negócio
9. [`admin-system.md`](admin-system.md) — manual do Administrador do Sistema (só para quem tem esse perfil)
10. [`troubleshooting.md`](troubleshooting.md) — problemas comuns
11. [`faq.md`](faq.md) — perguntas frequentes

## O que não está aqui

O módulo "Ofícios" aparece referenciado nas permissões do sistema mas **não tem nenhum ecrã
acessível no menu nem endpoint funcional no servidor** — não é um módulo que possa usar hoje,
apesar de o nome aparecer no código. Não documentado por não existir de facto. Ver
[`../known-issues.md`](../known-issues.md#oficios-modulo-fantasma).
