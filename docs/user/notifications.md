# Notificações e Mensagens

## Notificações

O sino de notificações mostra eventos relevantes para si (ex.: um pedido seu foi aprovado, uma
factura precisa da sua atenção). Notificações não lidas ficam destacadas; marcam-se como lidas
ao abri-las.

Se o seu PC tiver notificações push ativadas para o SIPAR-FADA, pode receber avisos mesmo com a
app em segundo plano — depende de configuração feita pelo Administrador do Sistema
(`VAPID_PUBLIC_KEY`/`VAPID_PRIVATE_KEY` no servidor); se essa configuração não existir na sua
instalação, as notificações continuam a aparecer normalmente dentro da app, só não chegam como
alerta do sistema operativo.

## Mensagens internas

Separado das notificações automáticas: mensagens internas trocadas diretamente entre
utilizadores do sistema, associáveis a um registo específico (ex.: uma factura, uma acta).
