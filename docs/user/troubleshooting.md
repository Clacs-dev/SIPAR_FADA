# Problemas Comuns

| Sintoma | Causa provável | O que fazer |
|---|---|---|
| A app não abre / fecha sozinha | Problema na instalação local | Contacte o suporte técnico da FADA |
| "Não foi possível ligar ao servidor" | Sem ligação à rede da FADA, ou o servidor central está em baixo | Confirme que está ligado à rede da FADA (não uma rede externa). Se outros colegas também não conseguem aceder, o problema é do servidor — reporte ao suporte técnico |
| Login falha com "credenciais inválidas" | E-mail ou password incorretos | Confirme o e-mail; use "Esqueci-me da password" se necessário |
| "Sessão terminada, faça login novamente" | A sua sessão foi terminada remotamente (ex.: por segurança) ou expirou | Inicie sessão novamente |
| Um módulo que preciso não aparece no menu | O seu perfil não tem essa permissão | Contacte o Administrador do Sistema |
| "Não tem permissão para esta ação" | A ação exige um perfil diferente do seu | Contacte o Administrador do Sistema se acha que devia ter acesso |
| Aviso de "licença a expirar/expirada" | Gerido centralmente | Reporte ao Administrador do Sistema — não é algo que resolva como utilizador comum |
| Upload de ficheiro falha | Tipo de ficheiro não aceite, ou maior que 10MB | Ver tipos aceites em [`documents.md`](documents.md) |
| Uma ação de eliminação não aparece na Lixeira | Só um Administrador do Sistema vê a Lixeira | Peça a um Administrador do Sistema para verificar/restaurar |
