# Reuniões Internas e Salas de Reunião

## Objetivo

Agendar reuniões internas e gerir a disponibilidade de salas físicas.

## Quem pode utilizar

- **Ver a sua agenda**: todos os utilizadores autenticados.
- **Criar/gerir reuniões**: gabinetes executivos, Gestão, Administração, Secretaria.

## Passo a passo (agendar uma reunião)

1. Escolher data, hora de início/fim, tipo de reunião.
2. Escolher uma sala física (o sistema verifica disponibilidade automaticamente e avisa de
   conflitos) ou uma plataforma online (Zoom/Teams/Google Meet, se configurada pela instituição —
   caso contrário, é usado um link fixo definido pelo Administrador do Sistema).
3. Adicionar participantes.
4. Depois da reunião, pode ligar-se diretamente à criação de uma Acta correspondente.

## Salas de reunião

Cada sala tem capacidade e recursos próprios, geridos pela equipa de gestão. O sistema impede
agendar duas reuniões na mesma sala em horários sobrepostos.
