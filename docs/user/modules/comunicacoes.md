# Comunicações

## Objetivo

Correspondência oficial, interna e externa (equivalente digital de um ofício/memorando).

## Quem pode utilizar

Consoante o seu perfil e departamento — verifique no menu lateral se "Comunicações" está
disponível para si.

## Passo a passo

1. Criar uma nova comunicação: assunto, mensagem, destinatários, prioridade.
2. Anexar documentos, se necessário.
3. Submeter — fica com estado **pendente** até ser despachada/processada pelo destinatário.

## Ações disponíveis

Despachar, responder, arquivar, eliminar (vai para a Lixeira).

## Regras importantes

A prioridade da comunicação (baixa/normal/alta/urgente) é apenas indicativa — não altera o fluxo
de aprovação automaticamente.
