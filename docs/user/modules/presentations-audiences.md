# Cartas de Apresentação e Audiências

## Objetivo

Gerir pedidos de visita/apresentação institucional (Cartas de Apresentação) e pedidos de
audiência com dirigentes da FADA.

## Quem pode utilizar

- **Criar um pedido**: utilizadores externos (`externo`).
- **Ver e gerir todos os pedidos**: gabinetes executivos, Gestão, gabinetes governamentais,
  Administração, Secretaria.

## Como aceder

Menu lateral → "Cartas de Apresentação" ou "Audiências".

## Passo a passo (criar um pedido)

1. Preencher os dados do requerente/empresa, o motivo do pedido e a data desejada.
2. Submeter.
3. O pedido fica com estado **pendente**, visível à equipa de gestão para aprovação.

## Campos principais

Nome/empresa, NIF, motivo, departamento pretendido, data desejada, contacto (nome/e-mail/telefone).

## Ações disponíveis (equipa de gestão)

Aprovar, rejeitar, atribuir, arquivar.

## Regras importantes

Um pedido eliminado vai para a Lixeira, nunca é apagado em definitivo — pode ser restaurado por
um Administrador do Sistema.
