# Actas

## Objetivo

Criar, redigir e aprovar atas de reuniões (internas ou associadas a uma Reunião Interna
agendada).

## Quem pode utilizar

- **Ver actas**: gabinetes executivos, Gestão, gabinetes governamentais, Administração,
  Secretaria, Jurídico.
- **Criar actas**: gabinetes executivos, Gestão, Administração, Secretaria.
- **Gerir (aprovar/arquivar)**: PCA, PCE, Administrador, Gestão.
- **Redigir como rascunho** (`DRAFT_ACTAS`): Secretaria, Administrativo.

## Como aceder

Menu lateral → "Actas".

## Passo a passo

1. Criar uma acta nova (pode estar associada a uma Reunião Interna já agendada).
2. Preencher pontos de agenda, participantes, decisões.
3. A acta segue o estado **rascunho** até ser submetida para aprovação.
4. Depois de aprovada, pode ser exportada para PDF a partir do ecrã de detalhe.

## Regras importantes

- Eliminação de uma acta move-a para a Lixeira.
- A exportação para PDF é gerada no seu computador a partir dos dados da acta — não depende de
  ligação ao servidor para esse passo específico.
